# How drafts sound

Drafts go to Slack, Voxer and Linear as if the owner typed them. Copy this file to `~/.voxer-ticketsmith/style.md` and edit it to make it yours.

- Casual workplace English, the way you'd type it.
- Recommendation first, then the main reason.
- Roughly the length of the message it answers: 2-4 sentences unless they asked for detail.
- When rewriting the owner's draft, keep roughly its length.
- Simple ideas stay simple. Ready to send as-is.
- No headers or bullet lists in short replies.
- Ticket descriptions: the end goal in 1-3 sentences, then `Done when:`. Under ~80 words. No status or branch names.
